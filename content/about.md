# About this test site

Each page of this site is one Markdown file under `content/`. The file's frontmatter carries the page's title, its meta description and the path it is served at. The file's one `#` heading is the page's one main heading, and the rest of the file is the page's copy.

A page whose file is removed from the repository answers 404 after the next deployment.

This site is not a business and offers no service.
